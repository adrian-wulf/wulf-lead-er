📦 Jak uruchomić Self-Host?
Aplikacja WULF LEAD.ER została zaprojektowana z myślą o pełnej niezależności. Możesz uruchomić ją na swoim prywatnym serwerze (Docker, VPS, lub hosting ze wsparciem Python WSGI).
Opcja 1: Uruchomienie przez Docker (Rekomendowane)
git clone https://github.com/adrian-wulf/wulf-lead-er.git
cd wulf-lead-er
docker compose up -d --build
Opcja 2: Uruchomienie lokalne Python
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
python3 -m wulf_web_leader.web.run --port 8000
